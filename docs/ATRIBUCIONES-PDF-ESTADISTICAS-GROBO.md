# Librerías PDF utilizadas por GROBO

Las exportaciones estadísticas incluyen en el frontend las distribuciones minificadas de:

- **jsPDF v2.5.1**, licencia MIT. Proyecto: https://github.com/parallax/jsPDF. Distribución: `front/dist/js/vendor/jspdf.umd.min.js`.
- **jsPDF-AutoTable v3.8.1**, licencia MIT. Proyecto: https://github.com/simonbengtsson/jsPDF-AutoTable. Distribución: `front/dist/js/vendor/jspdf.plugin.autotable.min.js`.

Se conservan las notificaciones de licencia de los paquetes originales. El uso de estos proyectos no implica patrocinio ni respaldo de GROBO por parte de sus autores.

Las bibliotecas se cargan **solo bajo solicitud de exportación PDF**. Se sirven desde el mismo dominio de GROBO para evitar que la descarga de informes dependa de terceros externos durante la exportación. No se incluyeron ni distribuyeron archivos de fuentes.
